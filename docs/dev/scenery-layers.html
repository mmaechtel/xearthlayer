Welches Paket X-Plane wo zeigt

Jede Kachel der Karte ist ein 1°×1°-Feld (eine DSF). Ihre Farbe zeigt das Paket, das dort gewinnt. Liegen mehrere Pakete übereinander, gilt die Schicht: eigene Pakete vor neuem XEL, neues XEL vor altem XEL. Leere Flächen sind Meer oder X-Plane-Standardtextur.

Wie X-Plane die Reihenfolge bestimmt

XEarthLayer legt alle Pakete in einen Ordner zusammen. Wo zwei Pakete dieselbe Datei haben, gewinnt der alphabetisch kleinere Code (klein geschrieben verglichen): - vor Ziffern, Ziffern vor Buchstaben. Deshalb tragen deine Pakete eine Ziffer an zweiter Stelle (E0_, E5_, N5_), die neuen XEL-Regionen einen Bindestrich (NA-…) und alle alten XEL-Pakete den Präfix ZY_. So bleibt die Schicht über alle Kontinente hinweg richtig.
